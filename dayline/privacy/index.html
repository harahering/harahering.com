プライバシーポリシー

施行日: 2026年○月○日

harahering(以下「開発者」)は、iPhone アプリ「Day Line」(以下「本アプリ」)での利用者の情報の取り扱いを、次のとおり定めます。

1. 利用者が書いた内容の保存場所

本アプリで作成したポスト(テキスト・写真・動画)、コメント、タグ、設定は、利用者の端末の中にだけ保存されます。開発者のサーバに送られることはなく、開発者がその内容を見ることはできません。本アプリにアカウントの登録はありません。

  • 端末のバックアップ(iCloud バックアップなど)には、Apple の仕組みに従って本アプリのデータも含まれます。設定で、写真と動画をバックアップに含めるかを選べます。
  • 「バックアップを書き出す」で作るファイルは、利用者が決めたパスワードで暗号化され、利用者が選んだ場所に保存されます。

2. タグのロック

ロックのパスコードは、元に戻せない形(ハッシュ)に変換して、端末のキーチェーンに保存します。Face ID・Touch ID による認証は iOS が端末の中で行い、開発者が生体情報を受け取ることはありません。

3. 利用状況の送信

本アプリの改善のため、どの機能が使われているかを、TelemetryDeck GmbH(ドイツ)が提供する分析サービス「TelemetryDeck」に送ります。

  • 送る内容: 行った操作の種類(例: ポストを作成した、タブを開いた、課金画面を開いた)と、それに付く決まった値(例: ポストの種類と件数、プランの種類)。
  • あわせて送られる情報: アプリと OS のバージョン、端末の機種、言語と地域、利用時間などの統計、端末ごとの識別子を元に戻せない形(ハッシュ)に変換した値。
  • 送らない内容: ポストの本文、コメント、タグ名、URL、写真・動画、検索した文字、氏名や連絡先など、利用者を特定できる情報。
  • 送った情報は統計としてだけ使い、広告や、ほかのアプリ・サイトをまたいだ追跡(トラッキング)には使いません。
  • 設定の「利用状況を送信」をオフにすると、送信を止められます。

TelemetryDeck での取り扱いは、TelemetryDeck のプライバシーポリシーをご覧ください。

4. 本アプリが外部と通信する場面

  • リンクのカード表示: ウェブページのリンク(X・Instagram・TikTok の投稿を含みます)だけをポストにすると、タイトルや画像を表示するため、端末からそのページに接続します。接続先での取り扱いは、それぞれのサイトのプライバシーポリシーに従います。
  • お知らせ: 新しいお知らせを確認するため、本サイト(harahering.com)からお知らせの一覧を読み込みます。本サイトは GitHub, Inc. のサービス(GitHub Pages)で公開しており、通常のウェブサイトと同様に、接続の記録(IP アドレスなど)が GitHub に残ることがあります。
  • 購入: プレミアムの購入・復元・解約は、Apple の App Store を通じて行います。支払いの情報を開発者が受け取ることはありません。

5. 写真ライブラリ

写真や動画を選ぶときは、iOS の写真選択画面を使い、利用者が選んだものだけを本アプリに取り込みます。写真ライブラリへの保存は、利用者が「画像を保存」を選んだときだけ行います。

6. 第三者への提供

開発者は、法令に基づく場合を除き、利用者の情報を第三者に提供しません。開発者が受け取る情報は、上記の利用状況の統計と、お問い合わせで利用者が送った内容だけです。

7. お問い合わせ

お問い合わせフォームから送られた内容(返信先のメールアドレスなど)は、お問い合わせへの対応にだけ使います。

8. 改定

このポリシーは、必要に応じて改定することがあります。大きな変更がある場合は、本サイトのお知らせでお知らせします。
